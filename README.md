# 抖音内容数据分析（进行中）

用数据回答一个问题：**什么样的选题和开头，更能带来播放和互动。**

这是一个持续更新的个人项目。数据按周固定采集，结论会随样本积累不断修正——当前所有发现均为阶段性结果，不作为最终定论。

---

## 这个项目在做什么

运营一个抖音账号，作品表现差异明显。为了不再靠主观感觉判断"发什么"，用数据分析代替拍脑袋：

1. 从抖音创作者后台导出作品数据；
2. 清洗数据、排除无效作品，手工标注两个内容维度；
3. 分组对比不同选题 / 钩子在播放、完播、互动上的差异；
4. 识别爆款对平均值的干扰，改用中位数与互动率评估真实表现；
5. 按周固定采集新数据，持续跟踪结论是否稳定。

## 用什么做的

- **Python + pandas**：数据清洗、分组统计
- **Jupyter Notebook**：可复现的分析流程
- **Excel**：后台导出与手工标注 topic / hook

## 怎么运行

1. 把抖音后台导出的作品数据放到本地，文件命名为 `作品列表导出.xlsx`；
2. 用 Jupyter 打开 `01_抖音数据首次分析.ipynb`；
3. 从上到下依次运行各代码格即可（代码里已标注数据文件路径，按需改成你自己的路径）。
